# 截图清单

1. 项目目录：展示 manifest.json、content.js、background.js、gallery 文件和 docs 文件夹。
2. Chrome 扩展管理：开启开发者模式，加载项目，截图「图提取 ImageGrab 1.0.0」。
3. 商品页：可先使用本地测试地址，截图商品和右下角「获取图片」按钮。真实平台截图需你自行登录并打开商品。
4. 图片工作台：提取后的图片网格、尺寸、全选/反选、已选数和下载按钮。
5. 大图预览：点击图片展示预览弹窗。
6. 下载结果：点击下载，待完成后截图成功/失败数，并在下载目录打开 ImageGrab 文件夹，展示 PNG 文件。
7. 官网首屏：打开 docs/index.html 或本地官网地址，截图产品介绍和界面示意。
8. 官网核心功能：滚动到六个功能卡片。
9. 官网安装步骤：滚动到四步安装说明。
10. 手机适配：浏览器 F12 切换手机尺寸（如 390 × 844），截图导航与功能卡片。
11. 如作业要求 Git：在项目目录执行 git log --oneline，截图本地提交记录。GitHub 推送需要真实仓库，不能用本地记录替代远程证明。
